# Portadas predeterminadas

Estas portadas son el respaldo visual mientras no exista una portada personalizada
en `../img`. Mantén el tamaño recomendado de **720 × 960 px** (proporción 3:4).

Puedes reemplazar `1.svg`, `2.svg` o `3.svg` por imágenes propias conservando el
nombre. La selección se hace automáticamente y no forma parte del formulario.
